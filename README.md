# Домашнее задание 1. HTTP-сервис

**ФИО:** Иванов Андрей Александрович

**Группа:** Б9125-02.03.01 сцт1

**Предметная область:**

Прокат транспорта.

Ресурсы:
- транспорт (`Vehicle`);
- клиенты (`Customer`).

Типы транспорта:
- автомобиль (`Car`);
- самокат (`Scooter`).

Автомобиль можно арендовать с 18 лет, самокат — с 16 лет.

Сервис поддерживает CRUD для транспорта и клиентов, аренду и возврат транспорта, а также фильтрацию транспорта по типу и доступности.

Данные хранятся в памяти.
